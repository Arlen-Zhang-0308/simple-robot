# nRF24L01 接线与联调

OLED 保持使用 SPI1；nRF24L01 使用独立 SPI2。

| nRF24L01 | STM32F103C8T6 | 用途 |
| --- | --- | --- |
| CE | PA8 | 收发模式控制 |
| CSN | PA4 | GPIO 片选，低有效 |
| SCK | PB13 | SPI2_SCK |
| M1 / MISO | PB14 | SPI2_MISO |
| M0 / MOSI | PB15 | SPI2_MOSI |
| IRQ | PB12 | EXTI12，下降沿通知接收任务 |
| VCC | 3.3 V | 禁止接 5 V |
| GND | GND | 共地 |

默认无线参数：通道 76、1 Mbps、5 字节地址 `E7:E7:E7:E7:E7`、Pipe 0、固定 32 字节无线载荷、自动应答开启。应用层帧使用现有 `AA 55` 协议；短帧以零填充至 32 字节发送，接收端会忽略填充字节。

IRQ 中断只通知接收待处理；SPI 读包、命令解析和响应发送在 CommTask 中完成，避免在中断上下文执行阻塞式 SPI 操作。PB15 已不再可作为 Wi-Fi EN 预留脚。
